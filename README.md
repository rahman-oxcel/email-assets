# email-assets

Images referenced by HTML emails, served through GitHub Pages so email clients can load them.

- `brokercore-logo.png`: the BrokerCore wordmark, 900x126, shown at 170x24.
- `icon-ideas.png`: lightbulb tile for the ideas card, 144x144, shown at 48x48.
- `icon-shield.png`: shield tile for the data protection band, 144x144, shown at 36x36.
